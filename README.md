# 成績簿 (Gradebook)

https://z88487561.github.io/gradebook/

一款輕量、零依賴、支援離線使用的漸進式網頁應用程式（PWA），專為教師、補習班與家教設計，用來快速登錄各科成績與學習狀況、追蹤學生趨勢並產出視覺化個人成績單。

## ✨ 主要功能

### 📝 考試與成績管理
- **快速登錄模式**：依科目切換輸入介面，輸入分數時即時計算並顯示該科名次；支援鍵盤 `Enter` 自動跳至下一位學生，留空即視為缺考。
- **逐科狀況與備忘登錄**：在成績輸入卡片中可直接為每位學生選擇該科狀況（**進步中**、**持平**、**需追蹤**）並填寫選填備忘，方便當下快速紀錄。
- **即時排名與統計**：支援依「總分」或「單一科目」排序（同分並列），自動計算有效人數、平均分、最高分與最低分。
- **視覺化圖表分析**：內建純手寫輕量 SVG 圖表，提供分數分布直方圖（10 分一級距，60 分以下自動標紅）與各科最高／最低／平均區間圖。

### 👨‍🎓 學生檔案與逐科狀況追蹤
- **批次建檔與分級**：支援一次貼上多行姓名批次新增學生，並可隨時調整所屬年級。
- **依狀況篩選與最新狀態摘要**：學生列表上方提供「全部」、「需追蹤」、「持平」、「進步中」篩選按鈕，並自動彙整每位學生各科最近一次的學習狀況標籤。
- **歷次學習狀況與備忘紀錄**：學生個人頁會按考試彙整各科狀況與備忘內容，並列出歷次考試的均分與總分名次。
- **個人歷次趨勢分析**：自動彙整單一學生的歷次考試表現，繪製「各科成績趨勢折線圖」、「總分名次變化圖」以及「最近一次考試能力雷達圖（與年級平均對照）」。

### 🖼️ 成績單匯出與分享
- **一鍵產出 JPG 成績單**：選擇特定考試後，系統會將個人各科分數、年級平均、名次、逐科狀況與備忘，搭配趨勢圖表渲染為高解析度（2x）JPG 圖片。
- **原生分享支援**：在支援 Web Share API 的行動裝置上，可直接透過系統分享選單傳送成績單圖片。

### 💾 離線運作、PWA 管理與資料安全
- **純本地端儲存（Local-First）**：所有資料皆儲存於瀏覽器的 **IndexedDB**（`gradebook` 資料庫），並於頁面隱藏（`visibilitychange`）或卸載（`pagehide`）時即時 flush 寫入，無需後端伺服器。
- **PWA 安裝與資料解除管理（`pwa-manage.js`）**：
  - 頂部列內建 `#pwa-slot` 容器，支援瀏覽器安裝提示（`beforeinstallprompt`）與 iOS／桌面安裝指引。
  - 提供本專案專屬的資料清除與解除安裝管理視窗，僅針對 `gradebook` IndexedDB 與 `gradebook-` 開頭快取進行清理，不會影響同網域下的其他 PWA。
- **雙重備份機制**：
  - **自動滾動備份**：每次資料變更時自動於本地保留最多 8 份歷史快照（間隔 10 分鐘），可隨時一鍵還原。
  - **CSV / JSON 匯出入**：支援單次考試成績的 CSV 匯出與批次匯入，以及全站資料的完整 JSON 備份與還原。

## 🛠️ 技術架構

本專案採用極簡原生技術棧，**無任何第三方框架或打包工具（Zero Dependencies / No Build Step）**：

- **前端核心**：Vanilla JavaScript (ES2022+)、HTML5、CSS3（支援深色模式 `prefers-color-scheme: dark` 與手機安全區域適配 `safe-area-inset`）
- **資料持久化**：IndexedDB (`kv` ObjectStore) + `navigator.storage.persist()` + `visibilitychange` / `pagehide` 即時寫入
- **PWA 管理模組**：獨立 `pwa-manage.js`（Shadow DOM 封裝安裝按鈕、狀態提示與前綴限定資料清除）
- **圖表繪製**：原生動態生成 SVG（折線圖、雷達圖、直方圖、區間圖）
- **圖片轉檔**：SVG `<foreignObject>` 結合 HTML5 `<canvas>` 匯出 JPEG
- **離線支援**：Web App Manifest + Service Worker（目前快取版本 `gradebook-v9`）
